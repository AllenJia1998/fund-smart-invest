# 基金分析方法论

分析一只基金时，按以下顺序取证，不要跳步、不要凭印象：

## 1. 基础识别
- 用 `search_fund` 把名称转成 6 位代码，再用 `get_fund_detail` 拿全称、类型、成立日、规模、经理、风险等级。
- 判断类型（股票型 / 混合型 / 指数型 / 债券型 / QDII / 商品型），不同类型不可直接比收益。

## 2. 业绩与回撤
- 用 `get_fund_history` 取 7d / 1m / 3m / 6m / 1y 多周期涨跌幅。
- 重点看**一致性**：如果只有近 1 月好、其余周期都差，属于短期博弈而非长期优质。
- 关注波动特征：近 10 个交易日净值的起伏幅度，反映波动率高低。

## 3. 横向对比
- 用 `get_fund_ranking` 确认同类位置，判断该基金在同类中的相对水平。
- 至少给出一个同类参照，避免孤立评价。

## 4. 结论框架
输出必须包含：
- **一句话结论**（值得关注 / 谨慎 / 不建议）
- **优势**（2-3 条，带数据）
- **风险**（2-3 条，带数据）
- **适合人群**（定投型 / 一次性配置 / 短线交易 / 不适合）
- **置信度**（0-100）并说明为何不是满分

## 禁止事项
- 不要使用"稳赚""必涨""保本"等表述。
- 不要在缺少数据时编造数值；数据缺失就写"数据不足"。
- 不要给出"买入 X 元"这类精确金额指令，只给仓位比例区间。
