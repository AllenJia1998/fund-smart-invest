# 图片与文档解读

用户上传的文件已由 harness 解析为文本（图片走 macOS Vision OCR，文档走正文提取）。请遵循：

## 解读顺序
1. **先复述你看到的原始内容**：把关键数字、表格字段、标题逐条列出，让用户能核对 OCR/解析是否准确。
2. **再给结论**：基于提取到的内容回答用户的问题。
3. **最后指出不确定处**：OCR 可能有误（尤其是数字 0/8、1/7，以及小数点），若某个数值对结论影响大，明确提示"请核对原文"。

## 针对不同文件类型
- **持仓截图**：识别基金名称、持有份额、持仓成本、当前市值、盈亏比例；计算总仓位与各基金占比，指出集中度风险。
- **净值走势图**：描述趋势形态（上涨/下跌/震荡）、关键拐点、波动幅度，并对照 `get_fund_history` 的真实数据交叉验证。
- **研报 / 公告**：提取核心观点、目标价、风险提示、发布日期，并判断时效性。
- **Excel / 数据表**：说明表结构（列含义）、数据范围、异常值，必要时用 `calculate` 做统计。

## 硬性要求
- 不要编造文件中没有的数字。
- 如果解析结果明显不完整或为空，直接说明"该文件未能有效解析"，并建议用户改用更清晰的图片或文本格式。
