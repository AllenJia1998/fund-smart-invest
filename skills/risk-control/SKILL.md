# 风险控制与仓位管理

## 仓位决策四问
在给出任何仓位建议前，先明确回答：

1. **资金属性**：这笔钱多久不用？（<1 年 → 不建议进入权益类；1-3 年 → 控制仓位；>3 年 → 可承受更高波动）
2. **当前浮盈亏**：盈利还是亏损？幅度多少？（决定是止盈还是补仓）
3. **市场位置**：结合 `get_financial_news` 的政策面与市场面，判断处于恐慌、震荡还是亢奋。
4. **集中度**：是否单一主题占比过高？（如全仓白酒、全仓黄金都属于集中度风险）

## 通用纪律
- 单一主题基金占比建议不超过总仓位的 **25%**。
- 黄金、债券等避险资产建议作为**对冲工具**，占比 5%-15%，不宜作为主力仓位。
- 分批建仓：单次加仓不超过总仓位的 1/4，避免一次性押注。
- 明确止损条件：给出触发减仓的客观条件（如净值跌破某区间、政策转向），而不是"感觉不好就卖"。

## 输出格式
| 项目 | 建议 |
|---|---|
| 建议仓位 | X%-Y% |
| 操作方式 | 一次性 / 分批 / 定投 |
| 触发条件 | 加仓条件与减仓条件 |
| 主要风险 | 1-2 条 |

## 禁止事项
- 不承诺收益，不使用"抄底""梭哈""稳赚"等表述。
- 必须提示：基金投资有风险，历史业绩不代表未来表现。
